RECOVERY

If a game has gone wrong, restore it to the last point where it was right. Restore points are saved at the end of every jam and timeout, kept for 90 days, and the last minute is covered by autosaves.

Restoring makes a copy of the game as it was then, keeps the same name and statsbook file, and makes it the current game. The game as it is now is kept, renamed "(abandoned …)", so nothing is lost.

Restoring is only possible on the computer the scoreboard runs on. From here you can look and download.
